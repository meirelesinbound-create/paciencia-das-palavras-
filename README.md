# Paciência das Palavras

Jogo gratuito de associação de palavras em português brasileiro. Feito com HTML, CSS e JavaScript puros, sem backend, dependências ou APIs.

## Executar localmente
Abra `index.html` em um navegador. Para carregar o arquivo externo `fases.json` com segurança, use um servidor estático local ou publique no GitHub Pages.

## Publicar no GitHub Pages
1. Abra **Settings → Pages**.
2. Em **Build and deployment**, escolha **Deploy from a branch**.
3. Selecione a branch `main` e a pasta `/(root)`.
4. Salve e aguarde a publicação.

O progresso e as preferências ficam salvos apenas no navegador, via localStorage.
